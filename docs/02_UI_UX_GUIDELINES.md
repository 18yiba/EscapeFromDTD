## 当前整合规范：DTD 原生视觉规范 v1.0

### 1. 风格定位

核心风格：清新、自然、简约。

视觉目标：采用高亮度的暖色调，营造舒适、稳定、适合策略思考的游戏氛围。

设计语言：

- 大圆角矩形
- 卡片化容器
- 扁平化图标
- 清晰的功能分区
- 轻量反馈，不制造额外视觉负担

### 2. 核心色彩系统

当前 v1.0 色彩系统完全同步 v0.9 版本配色，优先使用统一语义变量维护。

| 元素 | 颜色用途 | 建议色值 |
| --- | --- | --- |
| 全局背景 | `--dtd-bg-main` | `#FDF8EE` 米白 |
| 容器背景 | `--dtd-card-bg` | `#FFFFFF` 纯白 |
| 核心动作 | `--dtd-green` | `#4F6B4F` 森林绿 |
| 次要动作 | `--dtd-white-btn` | `#F8F9FA` 浅灰白 |
| 辅助文字 | `--dtd-text-sub` | `#666666` 深灰 |
| 路径强调 | `--dtd-path-red` | `#E57373` 柔和红 |

使用原则：

- 全局背景使用米白，保持清新、自然的基础观感。
- 主要按钮、确认动作、就绪状态使用森林绿。
- 容器、弹窗、手牌面板使用纯白卡片承载内容。
- 辅助文字使用深灰，避免纯黑造成压迫感。
- 路径强调只用于关键路径、警示或连接状态，不作为大面积背景色。

### 3. 布局逻辑

布局功能参考 Colonist 的清晰分区方式，但视觉保持 DTD 当前原生风格。

顶部状态栏：

- 保持现有宽度。
- 居中显示“当前回合”和“连通指标”。
- 作为全局局势信息区，不承载复杂操作。

中央主区：

- 保留现有圆角地图方格阵列。
- 地图区域仍是页面视觉重心。
- 不改变棋盘行为、路径判定或胜负规则。

右侧面板：

- 继承原有“手牌区”卡片样式。
- 上方区域新增“联机状态”小卡片。
- 下方区域保留手牌与“确认放置”按钮。
- 面板内部使用卡片层级区分状态、手牌、操作。

### 4. 新功能组件设计

#### 4.1 新手引导弹窗

组件名称：Tutorial Modal

外观：

- 纯白卡片背景。
- `20px` 圆角。
- 卡片内容居中，层级清晰。

内容结构：

- 上方：绿色页签，用于表达当前教程步骤或主题。
- 中间：示意图区域，风格参考 Finish 块的绘本感图片。
- 底部：巨大的森林绿“准备”按钮，作为明确的主行动。

设计要求：

- 弹窗只承担新手引导，不加入复杂动画。
- 示意图应帮助理解规则或操作，不替代游戏逻辑说明。
- 主按钮使用森林绿，按钮文案清晰直接。

#### 4.2 联机反馈

组件名称：Networking Feedback

就绪状态：

- 使用绿色对勾。
- 文案颜色采用森林绿。
- 状态表达应简洁明确，例如“已就绪”。

等待状态：

- 使用森林绿的微弱呼吸动画。
- 动画只用于提示等待中，不应干扰棋盘操作。
- 文案应说明当前等待对象或等待原因，例如“等待对手就绪”。

# 逃出地图岛 landing page 轻量需求
版本： v0.9.0

## 1. 页面目标

品牌传达： 科普空间导航/空间认知等概念，输出发展性定向障碍的正确认知，并突出空间认知训练游戏的重要性。

核心展示：这个 landing page 用于介绍《逃出地图岛》这款网页桌游，快速说明游戏独特的“地图探索 + 解谜逃脱”玩法,并点击开始游戏。

## 2. 目标用户

- 1 所有想要尝试游玩Escape from DTD 游戏的玩家

## 5. 响应式优化

重点优化移动端，必须保证：
    Hero 不拥挤
    SVG 不超屏
    按钮方便点击
    卡片不堆叠
    Footer 不错位
    导航不遮挡内容

桌面端：

    最大宽度控制
    留白舒适
    不要超宽

## 6. 交互和动画需求：

交互需求
    点击“双人对战”进入游戏双人对战模式；
    点击“AI对战”进入游戏AI对战模式；
    点击“规则说明”弹出规则弹窗；
    移动端导航折叠为菜单。
    【动画要求】

仅允许轻量动画：
    hover scale
    hover shadow
    hover rotate
    active scale
    不要：粒子特效，重型 motion，复杂动画库
